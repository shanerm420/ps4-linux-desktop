# ps4-linux-desktop
Debian 13 + XFCE Linux distribution for jailbroken PS4 consoles (reference target: PS4 Pro, Baikal southbridge, firmware 12.52). Two OpenOrbis PKGs: an installer and a ChromeOS-for-PS4 remover. Single fully-allocated ext4 image, no partition table. Status: PKG build verified, nothing tested on hardware.
